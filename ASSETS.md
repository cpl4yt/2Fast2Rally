# 2Fast2Rally — asset wishlist

Everything here is **optional and drop-in**. Put a file with the right name in the right
folder under `res/`, run `build.bat` (it copies `res/` next to the exe) and start the game.
Anything you haven't provided keeps using what's in the game now, so you can add things one
at a time. `logs/rally.log` lists what got loaded (look for `audio:`, `sfx:` and `voice:` lines).

Folders that don't exist yet are already created with a `README.txt` saying what goes in them.

## Where to get assets that aren't AI-generated

- **Record it yourself.** A phone is fine for most of this: your voice, a friend's car,
  gravel under your shoes, a car door, wind.
- **Freesound.org.** Filter by licence (CC0 = no credit needed, CC-BY = credit needed). Read
  each sound's description and skip anything that says it's generated.
- **Sonniss GDC Game Audio Bundle.** A free yearly pack of professional recordings, royalty-free.
- **ambientCG / Poly Haven.** CC0 textures and models, mostly photo-scanned.
- **Kenney, Quaternius.** CC0 hand-made low-poly models.

Always check each item's own page. Keep a note of where every file came from and its licence,
and send me the list so I can put it on the Credits screen.

## Priority 1 — biggest difference

### 1. Co-driver voice → `res/audio/codriver/`

A real voice calling the notes is the single biggest upgrade. Record **one word or phrase
per file**, named exactly as below. A missing word falls back to the TTS one.

| File | Say | File | Say |
|---|---|---|---|
| `left` | left | `right` | right |
| `1` | one | `2` | two |
| `3` | three | `4` | four |
| `5` | five | `6` | six |
| `hairpin` | hairpin | `square` | square |
| `long` | long | `tightens` | tightens |
| `opens` | opens | `dontcut` | don't cut |
| `caution` | caution | `overcrest` | over crest |
| `crest` | crest | `jump` | jump |
| `overbridge` | over bridge | `finish` | flat to finish |
| `into` | into | `and` | and |
| `50` | fifty | `70` | seventy |
| `100` | one hundred | `150` | one fifty |
| `200` | two hundred | `250` | two fifty |
| `300` | three hundred | `ready` | ready |
| `go` | go! | `goodluck` | good luck, let's go |
| `finished` | stage complete, nice driving | | |

- **Format:** `.wav` or `.ogg`, mono, 44.1 or 48 kHz.
- **Delivery:** quiet room, about 20 cm from the mic, fast and clipped like a real co-driver
  (they talk quickly). Keep the same energy and volume for every word.
- **Silence:** trimmed automatically, so a bit before and after is fine.
- **Tip:** say each word 3 times and keep the best take.

### 2. Engine sounds → `res/audio/cars/<pack>/`

Each car uses the folder named after its id (`kestrel`, `bianca`, …). To make several cars
share one recording, set `"sound": "<folder>"` on them in `res/data/cars.json`.

**What to record:** short loops of the engine held at a **steady RPM**, one file per RPM,
named with that RPM:

```
on_1000.wav  on_2500.wav  on_4000.wav  on_5500.wav  on_7000.wav     ← on the throttle (under load)
off_1000.wav off_2500.wav off_4000.wav off_5500.wav off_7000.wav    ← off the throttle (coasting)
```

- **Length:** 1–3 s each, with the RPM steady (no revving up or down inside a file). The game
  pitch-shifts and crossfades between neighbouring files and makes them loop seamlessly.
- **RPM steps:** 4–6 points from idle to near the redline. The numbers in the names only
  need to be roughly right.
- **Only one set?** That's fine. With just `on_` files the game makes the off-throttle
  sound itself (quieter and duller).
- **Easiest way to record:** car parked in neutral, phone 1–2 m behind and to the side of the
  exhaust (out of the wind), hold each RPM for ~5 s and cut a clean 2 s out. Name these
  `off_<rpm>`. For `on_` you need load: a steady pull uphill in a high gear, or a dyno.
- **Optional extras** in the same folder (`_1`, `_2`, … for variants):

  | File | What |
  |---|---|
  | `turbo` | Turbo whistle loop |
  | `backfire_1…` | Pops / bangs |
  | `blowoff_1…` | Blow-off valve |
  | `starter` | Starter motor catching |
  | `stall` | Engine dying |

What each car is supposed to sound like (any real engine of that type works):

| Folder | Car | Engine character |
|---|---|---|
| `kestrel` | Kestrel 4WD Turbo | 2.0 turbo 4-cylinder (90s WRC hatch) |
| `imperia` | Imperia Evo | 2.0 turbo 4-cylinder (rally saloon) |
| `vortex` | Vortex R1 | 1.6 turbo 4-cylinder, high-revving (modern WRC) |
| `quattra` | Quattra S1 | turbo 5-cylinder (Group B warble) |
| `bianca` | Bianca 2.4 | 2.4 V6, no turbo, revs to 7800 |
| `escala` | Escala Mk2 2.0 | 2.0 4-cylinder, no turbo, revs to 8500 (70s rally) |
| `vespera` | Vespera 1.6 | 1.6 4-cylinder hot hatch, no turbo |
| `mito` | Mito 1300 | small old 4-cylinder (classic mini) |
| `banshee` | Banshee T3 V8 | big V8 (rally raid) |

If you can only get 2–3 engines, use the `"sound"` field to share them. For example: one
turbo-4 pack for kestrel/imperia/vortex, one NA-4 pack for vespera/escala/mito, and the V8
for banshee.

### 3. Driving sounds → `res/audio/sfx/`

**Loops** (2–6 s, steady intensity; the game sets volume and pitch from speed and slip):

| File | Sound |
|---|---|
| `gravel_loop` | Tyres rolling on gravel (crunch + stones), recorded at speed if possible |
| `tarmac_loop` | Tyre roll / road noise on tarmac |
| `skid_loop` | Tyre squeal on tarmac |
| `snow_loop` | Tyres on packed snow |
| `grass_loop` | Driving on grass / soft ground |
| `wind_loop` | Wind noise at speed |
| `rain_loop` | Rain on the car |

**One-shots** (trimmed tight; add `_1`, `_2`, `_3` … variants so repeats don't sound the same):

| File | Sound |
|---|---|
| `impact_light_*` | Small knocks, scrapes, hitting a post |
| `impact_heavy_*` | Big crashes, metal crunch |
| `glass_*` | Headlight / glass breaking |
| `shift_*` | Gear-change clunk |
| `stones_*` | Single stones hitting the underbody (very short) |
| `backfire_*`, `blowoff_*` | Shared versions, if a car's pack has none |

## Priority 2

### 4. Menu & stage sounds

- **`res/audio/ui/`:** `click` (select), `move` (focus moves / hover), `back`
- **`res/audio/cues/`:**

  | File | When it plays |
  |---|---|
  | `beep` | Countdown 3-2-1 (replaces the built-in beeps) |
  | `go` | Start |
  | `split` | Split time |
  | `finish` | Crossing the finish |
  | `penalty` | Reset / corner cut |
  | `cheer_*` | Crowd cheer as you blast past spectators |

### 5. Ambience → `res/audio/ambience/`

Long loops (30 s+, stereo fine). The game picks one per stage, trying names in this order:
`<setting>_<day|night>` → `<setting>` → `day` / `night`.

| File | Sound |
|---|---|
| `forest_day` / `forest_night` | Birds, wind in trees / crickets, owls |
| `mountain_day` / `mountain_night` | Open wind, distant birds |
| `snow_day` / `snow_night` | Cold wind, quiet |
| `crowd` | Rally crowd murmur, fades in near spectator corners |

If that's too many, just `day.ogg` and `night.ogg` cover everything.

### 6. Textures → `res/textures/`

Seamless (tileable) photos, square, 512 or 1024 px PNG. Road textures repeat every 2.5 m.

| File | Replaces |
|---|---|
| `tarmac.png` | Tarmac road (currently noise) |
| `snow.png` | Snow ground (currently noise) |
| `snow_road.png` | Packed snow road (currently noise) |
| `mud.png` | Mud (currently tinted dirt) |

### 7. Music → `res/audio/music/`

Any number of `.mp3` / `.ogg` tracks; they play one after another on the menus. Make sure you
have the rights to every track.

## Priority 3 — bigger jobs (send them and I'll wire them in)

- **Car models (`.glb`, one per car).**
  - Real scale in metres, +Z forward, +Y up, origin at the centre of the body.
  - The 4 wheels as separate objects named `wheel_fl`, `wheel_fr`, `wheel_rl`, `wheel_rr`,
    each centred on its axle.
  - Optional `steering_wheel` object.
  - Materials named `body` (gets the livery colour), `glass`, `lights_front`, `lights_rear`.
  - Under ~20k triangles. Sizes roughly matching `halfExtents` in `cars.json`
    (e.g. Kestrel ≈ 1.76 m wide, 4.2 m long).
- **Spectators (`.glb`).** 2–4 low-poly people, standing, ~1.75 m tall, facing +Z, origin
  at the feet. A cheering/arms-up pose is a bonus.
- **Trackside props (`.glb`).** Start/finish gantry (space for the logo), banners, hay
  bales, tape posts, marshal flags, chevron signs.
- **Pace-note icons (PNG, white on transparent, 128 px).** Left/right 1–6, hairpin, square,
  crest, jump, bridge, finish. Currently drawn in code.
- **A different UI font** (any OFL font from Google Fonts) if you want another look.

## Format cheat sheet

- **Audio**
  - `.wav` (16-bit) or `.ogg` preferred; `.mp3` also loads.
  - Mono, except music and ambience (stereo is fine there).
  - 44.1 or 48 kHz. Peaks around -3 dB, no clipping.
  - The game levels the volumes itself, so loudness doesn't need to match exactly.
- **Images:** PNG, square, power-of-two size (512 / 1024).
- **Names:** lowercase, exactly as listed. Variants are `name_1`, `name_2`, …
